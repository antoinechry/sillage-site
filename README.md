# Sillage — site vitrine

Site vitrine de Sillage, la météo sur ta trace. Publié sur https://sillage-ride.eu via GitHub Pages (branche main, racine).

La page est générée depuis la maquette « Sillage — site vitrine » (artifact) par `tools/export.py` ; ne pas éditer `index.html` à la main sans reporter la modification dans la maquette.

Pages légales (`mentions-legales/`, `confidentialite/`, `supprimer-mon-compte/` et leurs versions anglaises sous `en/`) : générées par `tools/legal_pages.py` (`python3 tools/legal_pages.py .`) ; modifier le texte dans ce script, pas dans les pages.
